# OxygenOS & GMS Optimiser (OOSGMS-OPTIMISER)

A lightweight Magisk / KernelSU / APatch module designed for OxygenOS 16 / Android 16 to optimize Google Play Services background overhead and disable OnePlus/OPLUS telemetry.

## Key Features
- GMS Hardening via AppOps & Netpolicy
- OxygenOS & GMS Telemetry Stripping
- Smart 3-Minute Notification Sync Loop
- On-Demand Manual Sync via action.sh
